# SRS conformance audit, September 2026

Audit of the DMI code against ERA_ERTMS_015560 v4.0.0, carried out on
2026-09-18 at commit `f39c1d9` (branch `v4.0.0-update`). It replaces the
"remaining scope" notes in [PLAN.md](../PLAN.md) as the record of what is
open; PLAN.md §7 turns it into a prioritized backlog and refers to the
finding IDs used here.

of the branches `p0/fuzz`, `p0/ack-fifo`, `p0/st07-glyphs`,
`p0/input-hardening`, `p0/speed-dial-robustness`). Each fix re-verified

## Method and how far to trust it

Five read-only audits ran in parallel, one per group of chapters, done by
an AI agent. Each finding had to be backed by (a) the clause as read in the
specification text under
[SRS/ERA_ERTMS_015560_v400/sections](SRS/ERA_ERTMS_015560_v400/sections),
quoted by its number, and (b) the code location that shows the behaviour
is absent, partial or different. This rule exists because an earlier
analysis of this project contained invented clauses (PLAN.md §1).

Nothing was compiled or run by the audits themselves. The **Verified**
column says what was done on top:

| Mark | Meaning |
|---|---|
| R | Reproduced by running the DMI |
| O | Observed in a rendered frame or in the running browser bench |
| S | Spot-checked: clause text and code both re-read by a second pass |
| A | Audit only: clause and code location given, not independently re-checked |

Most findings are **A**. Re-read the clause and the code before acting on
one; treat the line numbers as of commit `f39c1d9`.

Classes: **MISSING** (nothing in the code), **PARTIAL** (simplified),
**DEVIATES** (the code does something different from the clause).

## Scope decisions

- **NTC is out of scope** (decided by the project owner, 2026-09-18).
  This covers chapter 9 (NTC default window, STM services) and chapter 12
  (NTC sub-level windows). Nothing exists for them in the code and nothing
  is planned. Interpretation used in this audit: what the *ETCS* chapters
  say about national systems stays in scope at display level, that is the
  level NTC symbols and announcement (8.2.3.2), mode SN in B7, the NTC
  text message class, and the chapter 15 messages that name an NTC.
- **Soft-key technology is out of scope** (decided by the project owner,
  2026-09-18): area H, the F1–F10 keys and the soft-key variants in
  6.3.1.6–6.3.1.9, 5.4.1.2, 5.4.1.6, 8.2.2.4.3, 8.3.10.6/.7 and
  8.5.2.7/.8. The code is touch screen only.

Not DMI gaps, but they shape what the DMI is shown:

  simulator invented it (`sim/evc_core.adb:457`). 8.2.3.8.4 requires only
  the LX01 symbol.
