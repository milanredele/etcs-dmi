# SUBSET-076 v4.0.0: ERTMS/ETCS test specifications

ERA, CCS TSI Appendix A, index 037b to 037d. The conformity tests of the
ETCS on-board against SUBSET-026, run on a reference test facility
(SUBSET-094). Only part 7, the scope, is in this folder, as PDF and as
markdown generated by [../tools/import_subset.py](../tools/import_subset.py)
(tables that span pages are split: check the PDF page, `<!-- end of page N -->`
comments, before relying on a detail). Parts 5-2 and 6-3 are 2.2 GB of zips
and are not committed: download them from the links below when they are
needed.

## What the on-board takes from it

The validation material of phases E3 to E5 ([EVC-PLAN.md §1](../../EVC-PLAN.md)).
Part 7, chapter 3 lists the SUBSET-026 requirements that are not testable, or
only in part, with the reason (Table 3), and which sequences need an optional
interface or a given radio system.

### What is in the zips (surveyed 2026-09-27)

**076-5-2, test cases.** 613 PDFs, 975 MB unpacked, one per SUBSET-026
feature and system version: `Subset-076-5-2-<feature>_v400_SV<xy>.pdf`,
where the feature number is the SRS section (3040200 is 3.4.2, Balise
co-ordinate system) and SV21, SV22 and SV30 (202, 203 and 208 files) are
the envelopes of system versions 2.1, 2.2 and 3.0. Each test case has an
identification block (tested feature, modes and levels, target, the
SUBSET-026 clauses it is based on), the method (what to check on which
interface), the starting conditions (mode, level, radio session, linking)
and the conditions on the interfaces. Text PDFs written by LibreOffice: the
text layer is clean and extractable.

**076-6-3, test sequences.** 3191 sequences (SV30 1144, SV21 1009, SV22
1038) over about 190 features per system version; 6.1 GB unpacked. Each
sequence is an inner zip `Subset-076-6-3_<feature>_<nn>_v400_SV<xy>.zip`
holding:
- a PDF (0.2 to 6 MB, typically 40 pages): the ordered list of test steps,
  grouped by the test cases of 5-2 they chain ("Feature 5040300: Test
  Case 7"), each step with the distance, the level and mode before and
  after, the event in words, I/O and interface (SIM, BTM, RTM, DMI, JRU,
  TIU, ODO); then the data of every stimulus, fully tabulated: each balise
  of each group variable by variable (name, length, value), each RBC
  message (Train Position Report, MA, SM Authorisation…) and each DMI
  event (event id, data, delay);
- an SVG (3145 of them): the chart of the sequence, MRSP and speed profile
  over distance;
- in 772 sequences, one or more `.xlsm` (1049 in all): the ERA braking
  curves simulation tool v5.1 (sheets Train, Track, National values, Fixed
  values, brake parameters, correction factors, curves; VBA macros) set up
  for that sequence, the expected braking curves.

There is no XML or database: the machine-readable content is the text
layer of the PDFs, where the telegram and message tables can be parsed
mechanically; the expected on-board reactions are sentences ("The Mode
symbol 'Stand By' is displayed", "CAB STATUS (NID_MESSAGE_JRU=38; M_MODE=6)
is recorded") and need a translation into the bench's checks.
