# SUBSET-034 v4.0.0: Train Interface FIS

ERA, CCS TSI Appendix A, index 007. The functional interface between the
ERTMS/ETCS on-board and the vehicle: every signal, its values and what the
rolling stock does with it. The PDF is the reference; `sections/` holds its
text as markdown for searching and reading, generated by
[../tools/import_subset.py](../tools/import_subset.py). Tables that span
pages are split, formulas and figures are lost or garbled: check the PDF
page (`<!-- end of page N -->` comments) before relying on a detail. A
clause starts its own line: `grep -rn '^2.3.1.3.1 ' sections/`.

## What the on-board takes from it

The TIU port ([EVC-PLAN.md §1](../../EVC-PLAN.md)). The electrical interface
is out of scope; the port carries the signals of chapter 2 as typed Ada
values, and the on-board implements the SUBSET-026 side of each (the SRS
clauses behind every function are listed in 2.9).

| Signals | Direction (seen from the on-board) | Clauses |
|---|---|---|
| Sleeping, passive shunting, non-leading permitted | input | 2.2.1 to 2.2.3 |
| ETCS isolated, in AD mode, remote shunting permitted | output | 2.2.4 to 2.2.6 |
| Service brake command, emergency brake command | output | 2.3.1, 2.3.3 |
| Brake pressure (service brake feedback) | input | 2.3.2 |
| Special brake inhibition, trackside and STM orders | output | 2.3.4, 2.3.5 |
| Special brake status, additional brake status | input | 2.3.6, 2.3.7 |
| Track condition orders: traction system, powerless sections, pantograph, air tightness, station platform, main power switch, allowed current | output | 2.4.1 to 2.4.8, 2.4.10 |
| Traction cut-off; engine orientation in SM | output | 2.4.9, 2.4.11 |
| Cab status, direction controller, train integrity, traction status, set speed | input | 2.5 |
| Type of train data entry, consist length, other train data, train running number | input | 2.6, 2.7 |
| National system isolation | input | 2.8 |
| Which functions a vehicle must, may or need not provide | — | 3, Table 4 |
