# SUBSET-130 v1.0.0: ATO-OB / ETCS-OB FFFIS Application Layer

ERA, CCS TSI Appendix A, index 087. The packets exchanged between the ATO
on-board and the ETCS on-board; the lower layers are SUBSET-143 (not in the
repository), the requirements behind the data are SUBSET-125
([../SUBSET-125_v110](../SUBSET-125_v110/README.md)) and SUBSET-026. The
PDF is the reference; `sections/` holds its text as markdown for searching
and reading, generated by
[../tools/import_subset.py](../tools/import_subset.py). The clause numbers
of this PDF are images: the tool read them back with OCR and checked them
against the PDF outline (all 42 entries found). Tables that span pages are
split: check the PDF page (`<!-- end of page N -->` comments) before
relying on a detail. A clause starts its own line:
`grep -rn '^6.2.2.2 ' sections/`.

## What the on-board takes from it

The ATO port ([EVC-PLAN.md §1](../../EVC-PLAN.md)): the ATO on-board of
`sim/evc_ato` becomes a separate module on this port. The packet list is
Table 2 in [6.1](sections/06_packet_description.md); the variables of each
packet follow in 6.2:

| Packet | Name | From → to | Cycle / timeout (ms) | Clause |

| 0 | ATO_ETCS_Status | ATO → ETCS | 100 / 1000 | 6.2.1.1 |
| 1 | ATO_ETCS_DMI | ATO → ETCS | 100 / 1000 | 6.2.1.2 |
| 2 | ATO_ETCS_Data_Entry_Need | ATO → ETCS | event | 6.2.1.3 |
| 3 | ATO_ETCS_Data_Entry_Request | ATO → ETCS | event | 6.2.1.4 |
| 4 | ATO_ETCS_Data_View_Values | ATO → ETCS | event | 6.2.1.5 |

| 7 | ETCS_ATO_Driver_Inputs | ETCS → ATO | 100..200 / 1000 | 6.2.2.3 |
| 8 | ETCS_ATO_Data_Entry_Values | ETCS → ATO | event | 6.2.2.4 |
