**4.2** **Terms & abbreviations**


4.2.1.1 For general terms, definitions and abbreviations refer to document [1]. New terms and
abbreviations used in this document are specified here.

|Table 2 : Terms|Col2|
|---|---|
|**Term**|**Definition**|
|Border|rectangle surrounding objects in order to create 3 dimensional<br>impression on the total image display area|
|Button|object shown to the driver through which a driver action is possible to<br>give input to the ERTMS/ETCS onboard. The object is identified by a<br>label.<br>When using a touch screen technology, the driver action is done via<br>the associated sensitive area on the display area.<br>When using a soft key technology, the driver action is done via the hard<br>key adjacent to the label|
|Cell|basic unit to define the shape of DMI objects and the proportions of<br>areas. Depending on the resolution of the total image display area, a<br>cell can consist of one or more pixels.|
|Dialogue Sequence|is a mechanism by which the DMI guides the driver through a set of<br>windows in order to fulfil a specific task.|
|Disabled|means the related button cannot go to the “pressed” state. A disabled<br>button does not respond to any driver actions.|
|Display area|zone displaying a piece of visual information and defined by a size (in<br>cells) and a position relative to the positions of the other display areas.<br>It is more commonly named “area” in this specification.|
|Enabled|means the related button can go to the “pressed” state. An enabled<br>button does respond to a driver action.|
|Frame|conspicuous rectangle surrounding an object|

|Table 2 : Terms|Col2|
|---|---|
|**Term**|**Definition**|
|Grid array|area grid pattern on the total image display area consisting of cells<br>which results in a visual appearance of information in certain<br>proportions|
|Hard key|physical key not part of the total image display area. This key can<br>also have a text label or symbol|
|Input field|object shown to the driver to echo a data.It is composed of a label<br>part giving the topic of the data and of a data part showing the data<br>itself.|
|Label|symbol or text indication on a button or associated to an input field|
|Layer|groups all areas with the same impression of depth using the border<br>technique|
|Pressed|means a driver action on the button is ongoing.|
|Sensitive area|area on which a driver can make a physical action to give input to the<br>ERTMS/ETCS onboard|
|Soft key|context-dependent key which consists of a hard key with an associated<br>label on the total image display area|
|Symbol|presentation of information in graphical form instead of using text|
|Total image display area|Image formed by the contribution of all individual display areas|
|Touch screen|Using the display area for driver’s inputs by means of programmable<br>sensitive areas|
|Window|a presentation of objects, text messages, input fields and/or buttons<br>related to a single topic.|
