# SUBSET-035 v4.0.0: Specific Transmission Module FFFIS

ERA, CCS TSI Appendix A, index 008. The interface between the ETCS
on-board and the STMs that run national train protection systems: the
bus, connection and version management, the STM states, and the STM
functions (control, TIU and BIU, odometer, DMI, juridical data). The PDF is
the reference; `sections/` holds its text as markdown for searching and
reading, generated by [../tools/import_subset.py](../tools/import_subset.py).
Tables that span pages are split, figures are lost: check the PDF page
(`<!-- end of page N -->` comments) before relying on a detail. A clause
starts its own line: `grep -rn '^8.2.1.1 ' sections/`.

## What the on-board takes from it

Nothing to implement ([EVC-PLAN.md §1](../../EVC-PLAN.md)): STMs and
national systems are out of scope, as for the DMI (PLAN.md scope decision).
Level NTC and mode SN exist as a level and a mode, without an STM interface.
The document is here to show where the boundary is when SUBSET-026 refers
to it.
