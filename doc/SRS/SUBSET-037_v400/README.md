# SUBSET-037 v4.0.0: EuroRadio FIS

ERA, CCS TSI Appendix A, index 010a to 010c, in three parts: part 1, the
communication layer and coordination function (GSM-R circuit and packet
switched, FRMCS); part 2, the safety layer (safe connection set-up with
authentication, SaPDUs and MACs, keys); part 3, the interface to FRMCS. The
PDFs are the reference; `sections/` holds their text as markdown for
searching and reading, generated by
[../tools/import_subset.py](../tools/import_subset.py), one file per chapter
prefixed with the part number (`2_06_safe_functional_module.md`). Tables
that span pages are split, figures are lost: check the PDF page
(`<!-- end of page N -->` comments) before relying on a detail. A clause
starts its own line: `grep -rn '^6.2.3.3.3.1 ' sections/`.

## What the on-board takes from it

The RTM port ([EVC-PLAN.md §1](../../EVC-PLAN.md)) delivers the radio
messages of SUBSET-026 chapter 8. The communication session set-up of
SUBSET-026 3.5 is in the EVC; this document below it, the safety layer
(SaPDU, keys) and the mobile network, is not. It gives the service
primitives the session management sits on (connection establishment, data,
release, and the reasons of a release).
