# SUBSET-027 v4.0.0: FIS Juridical Recording

ERA, CCS TSI Appendix A, index 005. The messages the ETCS on-board sends to
the juridical recording unit: their list (4.2.1), common fields (4.2.3),
the layout of each message (4.2.4) and the events that trigger them (4.3).
The PDF is the reference; `sections/` holds its text as markdown for
searching and reading, generated by
[../tools/import_subset.py](../tools/import_subset.py). Tables that span
pages are split: check the PDF page (`<!-- end of page N -->` comments)
before relying on a detail. A clause starts its own line:
`grep -rn '^4.1.1.2 ' sections/`.

## What the on-board takes from it

The JRU port ([EVC-PLAN.md §1](../../EVC-PLAN.md)) receives the events the
on-board must record: the triggering events of 4.3 and the content of the
messages of 4.2.4 define them. The recording device, its storage and file
format are out of scope. SUBSET-076 sequences check many steps on the JRU
("CAB STATUS (NID_MESSAGE_JRU=38) is recorded"), so the port keeps the
message numbers of 4.2.1.
