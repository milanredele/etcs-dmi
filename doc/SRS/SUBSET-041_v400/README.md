## What the on-board takes from it

The odometer port ([EVC-PLAN.md §1](../../EVC-PLAN.md)) delivers distance
and speed with their confidence intervals; the accuracy they must meet, and
the response times of the cyclic executive, are here. The values, all in
[chapter 5](sections/05_values_for_technical_performances.md):

| Performance | Value | Clause |
|---|---|---|
| Balise message received → emergency brake | < 1 s | 5.2.1.1 |
| Balise message → communication session set-up started | < 1.5 s | 5.2.1.2 |
| Balise message → resulting status change reported (EOA, level, mode) | < 1.5 s | 5.2.1.3 |
| MA by radio → EOA/LOA updated | < 1.5 s | 5.2.1.4 |
| MA from Euroloop → EOA/LOA updated | < 1.5 s, < 3 s unsynchronised | 5.2.1.5 |
| Emergency message → brake order, driver indication | < 1 s, < 1.5 s | 5.2.1.6 |
| Radio message → communication session set-up started | < 1 s | 5.2.1.7 |
| EOLM passed → first loop message decoded | 4 s | 5.2.1.8 |
| Driver action → new window displayed | 2 s | 5.2.1.10 |
| Awakening performance parameters #1, #2 | 3 s, 15 s | 5.2.1.11, 5.2.1.12 |
| EOA (level 1), LOA or former EOA/LOA passed → emergency brake | < 1 s | 5.2.1.13 |
| Distance measured on-board | ± (5 m + 5 % s) | 5.3.1.1 |
| Speed known on-board | ± 2 km/h below 30 km/h, linear to ± 12 km/h at 500 km/h | 5.3.1.2 |
| Age of speed and position in a position report | < 1 s | 5.3.1.3 |
| Safe clock drift | 0.1 % | 5.3.2.1 |
